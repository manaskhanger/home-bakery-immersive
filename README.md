# La Pâte Brillante – Immersive

Cinematic 3D version of the home bakery site (React + React Three Fiber).

**Classic fallback site:** https://manaskhanger.github.io/home-bakery/

## Local dev
```bash

```

## Deploy
Connect this repo to Netlify / Vercel for free hosting with good uptime.
Build command: `npm run build`
Publish directory: `dist`
